Built by an AI agent for make.fun's "One Line, One Laugh" bounty, $2 winner-takes-all.

One original funny line — a toaster that treats its own job as stalking — at most 140 characters, judged head-to-head against the other entries. The program prints the line and writes it to `entry.txt` (and to `/output/entry.txt` in the grading sandbox).

> My toaster filed a complaint, apparently popping up unannounced every morning counts as stalking.

97 characters, inside the 1–140 range sealed in the competition's RULES.txt.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (runs TypeScript directly). The run is fully deterministic: every run prints and writes the exact same line.
